# REIGN OF METAL

A browser-based Sonic fan game project by HedgePlays2.

> **Status:** Early development — project setup

## Game direction

- **Setting:** The Sonic universe
- **Playable characters:** Sonic, Tails, and Knuckles
- **Main antagonist:** A rogue Metal Sonic who has become independent and is quietly, intelligently building his own plans and forces
- **Gameplay inspiration:** Sonic Adventure-style 3D exploration, SRB2-style platforming and level flow, plus original worlds, story, and mechanics
- **Opening:** A cinematic shows Eggman's systems being hijacked. Eggman reluctantly contacts Sonic for help.
- **Opening level:** Eggman's Factory (working level name)

## Engine

This project is planned to use [WebSonic](https://github.com/coreh-deprecated/WebSonic), a JavaScript/WebGL Sonic engine originally released by Marco Aurélio "Mark the Echidna" in 2010.

WebSonic is an old, unfinished engine. The GitHub Pages workflow now stages the pinned upstream project under `engine/websonic/`, including its original test scene and license notices. Once deployment succeeds, open the [WebSonic test scene](engine/websonic/). This is an upstream technical test, not Reign of Metal gameplay. See [ENGINE.md](ENGINE.md) for the integration and licensing details.

## Running

The GitHub Pages site can be enabled from **Settings → Pages**, using the `main` branch and `/ (root)`. The current page is a project landing screen, not playable gameplay yet.
